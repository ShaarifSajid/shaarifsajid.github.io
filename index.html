Projects

Public Health Equity Mobile Care Broker

Oct 2026

Google Agents for Impact Hackathon, Atlanta · Python, Google ADK, Gemini, BigQuery, Cloud Run

A multi-agent system that plans where a county's mobile health clinic should operate each week and explains the choice to residents in plain language. A planner agent ranks census tracts on clinical need, uninsurance, and transit access without ever seeing race. A separate auditor agent checks the plan against demographic data the planner is denied and sends it back for revision if it falls short. A third agent writes the final plan. The agents share state through Google ADK, read public federal health data from BigQuery through Google's managed MCP server, and run on Cloud Run.

My part: the shortage-area data model in BigQuery, the plan-and-audit loop between the planner and auditor, and simplifying the interface for non-technical users.
